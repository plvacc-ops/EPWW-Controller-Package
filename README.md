# Welcome

Repository of VATSIM FIR EPWW sector files package (PLVACC)

A new release will be published in line with each AIRAC cycle (as long as significant changes warrant such a release).

[Ground Radar Plugin](https://forum.vatsim-scandinavia.org/t/groundradar) - thanks to Juha Holopainen

[Initial Climb Plugin](https://github.com/rpuig2001/InitialCimbPlugin) - thanks to [@rpuig2001](https://github.com/rpuig2001)

P21 - thanks to Matt Zymla and HSO
